# VoiceMemory

**让每一次对话，都值得被记住。**

VoiceMemory 是一款专为 Mac 与 iPhone 打造的智能语音记录与管理工具。

集录音、内容整理、人物管理、项目归档与智能摘要于一体，让重要的声音不再散落，让每一次交流都有迹可循。

专注记录，轻松整理，随时回顾。

产品关键词：`语音记录` `人物管理` `智能整理` `项目归档` `隐私优先`

在线查看：<https://wyihao2010-code.github.io/VoiceMemory-website/>

## 核心功能

| 功能 | 一句话介绍 |
|---|---|
| 语音记录 | 让重要交流完整留存。简洁直观的录音体验，轻松记录会议、访谈与日常交流。 |
| 内容整理 | 从声音到清晰的文字。将录音内容整理为可阅读的文字，帮助快速回顾重要信息。 |
| 人物管理 | 让每个声音都有归属。建立专属人物档案，关联对话记录，让人物与内容管理更加清晰。 |
| 智能摘要 | 告别冗长的信息整理。从记录中提炼重点内容、重要事项与关键信息，提高回顾效率。 |
| 项目管理 | 让记录井然有序。按项目集中管理录音和相关内容，构建清晰的信息归档体系。 |
| 历史回顾 | 重要信息，随时找回。通过分类与搜索快速定位历史记录，减少重复整理的时间。 |

## Mac 与 iPhone，共用一个账号

- **一个账号，两台设备**：邮箱注册与登录，Mac 与 iPhone 使用同一账号，可通过加密包迁移项目与人物。
- **数据留在各自本机**：录音、转写默认保存在本机；可主动加密迁移，开启 iCloud 同步时部分结构化数据与已确认声纹向量会同步，登录不会上传它们。
- **迁移与备份都加密**：项目与人物通过加密迁移包在设备间互传，录音包含音频与说话人标签。
- **系统要求**：Mac 版适用于 macOS 14 或更新版本的 Apple Silicon Mac；iPhone 版适用于 iOS 17 或更新版本。

## 账号与权益

云端账号用于身份与权益；iPhone 需要登录，Mac 的本机核心功能可不登录使用：

- **Free**：核心体验完整可用——录音、本机转写、人物确认、项目归档与基础导出。
- **Pro**：进阶能力通过权益解锁，兑换码即可激活。
- **你的数据不属于云端**：注册与登录密码会提交账号服务验证；iPhone 需登录，Mac 可不登录使用本机核心功能。

## 产品优势

- **专注于真正重要的内容。** 不只是录音，更关注录音之后的信息整理、人物关联与持续管理。
- **为长期积累而设计。** 从单次录音到项目归档，让分散的声音逐渐沉淀为有序、可回顾的信息。
- **尊重用户的数据与隐私。** 重视个人记录的自主管理，帮助用户在便捷使用与隐私保护之间获得更好的体验。

## 适用场景

- **工作会议**：记录会议内容，整理讨论重点与后续事项。
- **人物访谈**：保留重要对话，按人物关联和整理交流内容。
- **项目协作**：将不同阶段的交流记录集中归档，方便追溯。
- **学习交流**：留存课程、讨论与知识分享中的重要信息。
- **日常记录**：记录值得保留的声音，让珍贵的信息不再遗失。

## 隐私保护

你的记录，值得被认真保护。

VoiceMemory 重视用户的隐私与数据自主权：

- **本机优先**：核心录音、转写与人物资料在设备上完成和保存。
- **摘要由你触发**：智能摘要按需生成，只有你主动选择并确认，相关内容才会发送给所选服务。
- **无追踪**：应用不含统计埋点、崩溃上报或广告追踪。
- **账号最小化**：账号服务处理邮箱、密码及应用生成的设备标识；登录本身不会上传录音或转写。

数据处理、账户服务与隐私保护的具体说明，请参阅应用内的正式隐私政策。产品宣传文案不替代正式隐私政策，我们仅描述实际已验证的能力，不做超出实际能力的承诺。

## 关于 VoiceMemory

**为记录而生，为回顾而设计。**

每天都有大量有价值的信息产生于人与人之间的交流。但随着时间流逝，重要的观点、讨论和灵感，常常消失在记忆之中。

VoiceMemory 希望改变这种体验。我们相信，录音的价值不只是保存声音，更在于让信息能够被理解、整理与重新发现。

因此，我们希望通过更简洁、更自然的方式，让语音记录成为日常工作与生活中真正有用的工具。

**记录声音，留住价值。**

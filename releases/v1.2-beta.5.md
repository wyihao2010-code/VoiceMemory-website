# VoiceMemory 1.2 Mac Build 96 测试版（2026-10-27）

本次更新 Mac 安装包至 Build 96；该页为历史版本说明，当前下载请见最新版本。

## Mac 更新

- 项目页右侧可按当前录音的说话人和关键词共同筛选转写片段；切换录音后恢复全局搜索。
- “一键确认”先提示影响范围，只确认当前显示的片段；选定的人物与声纹反馈、纠错记录同步更新。
- 增加“重置识别”，可经确认后恢复该录音的初始人物识别结果。
- 调整搜索行和说话人下拉按钮的布局，使名称居中于两侧图标之间，长名称不与图标重叠。
- 回退此前的词典纠正处理，保持历史转写兼容。

## 安装与验证

- Mac：macOS 14+、Apple Silicon。本地签名且未经 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许。
- 此包不保证 CloudKit 在其他 Mac 上可用；iCloud 同步尚未开放。
- 已通过项目 SDK 门禁测试、公开包冷启动门禁、发行审计、签名验证、DMG 完整性与包内 Build 96 核对。构建来源：VoiceMemory `master` 的 `8749ac4`。

# VoiceMemory 1.2 测试版更新（2026-10-13）

当前下载提供 Mac 1.2（Build 52）与 iPhone 1.2（Build 5）。Mac 已从 Build 37 更新至 Build 52；iPhone 包内容和签名没有变化，因此保留其独立 Build 5 编号。

## 更新

- Mac 使用 MacOSX27.0.sdk 构建，包内写入已签名的 SDK 27.0 构建记录，并增加防止以后回退 SDK 的构建门禁。
- 延续 1.2 的文字定位播放、iPhone 导出分享条目、可信录音日期摘要、双端离线隐私政策和 iPhone 新图标。
- Mac Release 测试执行 282 项，4 项跳过、0 失败；冷启动自动门禁、签名、发行审计和 DMG 完整性验证通过。真实设备上的跨端播放及分享交互仍需验收。

## 安装限制

- **Mac DMG：** 本地签名，未经 Apple 公证。首次打开时，macOS 可能要求在“系统设置 → 隐私与安全性”中手动允许。支持 macOS 14+ 的 Apple Silicon。当前测试包不提供可用的 iCloud 同步功能。
- **iPhone IPA：** Apple Development 签名，仅签名描述文件中已登记的 **1 台测试设备**可安装。描述文件于 **2026 年 10 月 18 日**到期，届时需重新签名。使用 Apple Configurator 或 Xcode 安装；支持 iOS 17+。
- 在线购买尚未开放，当前权益以兑换码方式发放。

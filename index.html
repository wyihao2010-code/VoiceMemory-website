01 / SAME ACCOUNT

一个账号，两台设备

邮箱注册与登录，云端账号只承载身份与权益；项目与人物可通过加密包迁移。

02 / LOCAL DATA

数据留在各自本机

录音与转写默认保存在本机；你可主动导出加密包。iCloud 同步尚未开放；后续如提供并由你主动开启，已确认声纹向量可能跨设备传输。

03 / ENCRYPTED MOVE

迁移与备份都加密

项目与人物通过密码加密包互传，录音包含音频与说话人标签；完整备份另含恢复密钥。

01 / LOCAL

录音与转写在本机

核心录音、转写和声纹分析在设备上完成。已确认声纹以本机密钥加密保存；应用不含统计埋点、崩溃上报或广告追踪。

02 / REVIEW

人物与草稿需确认

声纹候选不是身份事实。外部导入、事件和 Agent 摘要草稿经过应用内审核。

03 / OPTIONAL AI

云端摘要由你触发

你主动生成摘要时，转写及已确认说话人信息会发送给所选服务。加密包分享和获授权的 Agent 读取也由你控制。

注册与登录会向账号服务提交邮箱、密码及应用生成的设备标识。登录本身不会上传录音或转写；iCloud 同步尚未开放；后续如提供并由你主动开启，部分结构化数据与已确认声纹向量可能跨设备传输。完整说明见隐私政策。
